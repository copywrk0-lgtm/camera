# UNMADE — Copywrk Digital Experiment 001

An independent interactive concept for Copywrk's first Instagram Reel.

## Run

1. Open a terminal inside this folder.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local address printed in the terminal.

The Three.js module is loaded from jsDelivr at runtime, so a working internet connection is required. No model download is necessary: the camera is constructed from real-time 3D geometry in `src.js`.

## Record

Use a desktop browser (ideally 1440×900) at 100% zoom. Scroll from the hero through the sticky scene in a single gentle movement. Capture the first frame, the exploded optical elements and the reassembly. For a vertical 9:16 Reel, record at 390×844 or crop a centered browser recording. On mobile, the 3D scene remains scroll-controlled; the buttons are optional shortcuts.

## Project safety

This is a standalone prototype. No existing GitHub repository or Vercel deployment was changed.
